# Arquivo

Memória fria. O que saiu do `_contexto/` por consolidação mora aqui: lição que já
virou regra dentro de uma skill, decisão antiga, fato de negócio que deixou de
mudar o que se faz hoje.

Nada daqui entra em conversa automaticamente. Serve pra quando alguém perguntar
"por que a gente decidiu assim?" e for preciso procurar.

Quem escreve aqui é o `/atualizar`, quando um arquivo do `_contexto/` bate o teto.
