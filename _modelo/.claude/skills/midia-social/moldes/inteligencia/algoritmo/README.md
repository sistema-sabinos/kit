# Notas de plataforma

> Como cada rede distribui post (frequencia, horario, hashtag, duracao). Regra de plataforma muda
> sem aviso, entao toda nota aqui leva a data em que foi conferida e a fonte.

## Regra

- Uma nota por assunto, com o nome `<assunto>-AAAA-MM-DD.md`.
- Toda nota abre com "conferido em AAAA-MM-DD" e o link da fonte.
- Nota com mais de 90 dias nao vale como verdade: antes de usar, pedir ao Claude pra conferir na
  internet (em ingles tambem) e escrever uma nota nova com a data de hoje.

## Formato

```
# <assunto>

conferido em AAAA-MM-DD
fonte: <link>

## O que vale
-

## O que muda pra nos
-
```
